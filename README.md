# 游戏人生 - 个人日程管理 PWA

> 把生活变成一场游戏，用积分养成好习惯。

一个零依赖的纯 HTML/CSS/JS 个人日程管理应用，将工作任务、养生习惯、学习计划、心愿奖励整合为一体，通过积分系统让自我管理变得有趣。支持 PWA 离线使用，安装到手机桌面后如同原生 APP。

---

## 项目特点

- **零依赖单文件** — 整个应用只有一个 `index.html`（约 84KB），不依赖任何框架或第三方库，打开即用
- **PWA 离线可用** — 支持 Service Worker 缓存，无网络环境下也能正常使用
- **可安装到桌面** — iOS Safari 和 Android Chrome 均支持"添加到主屏幕"，全屏 APP 模式运行
- **数据完全本地化** — 所有数据存储在浏览器 localStorage 中，无需后端服务器，隐私安全
- **莫兰迪灰粉设计** — 低饱和度温柔配色，圆角卡片 + 柔和渐变，高端低调
- **刘海屏适配** — 自动适配 iOS 安全区域（safe-area-inset），内容不被遮挡
- **语音添加任务** — 支持语音输入，自动识别时间和紧急程度

## 功能模块

### 1. 工作台

管理你的日常待办事项，让工作井井有条。

- 欢迎语 + 当前日期 + 天气信息
- 今日待办 + 近期待办列表，按紧急程度分类
- **语音添加任务** — 按住底部语音按钮说话，自动识别任务名称、时间、紧急程度
- 手动添加任务，支持自定义时间和优先级
- 任务按紧急 / 重要 / 普通三级分类，颜色区分
- 完成任务自动获得积分（紧急 200 / 重要 150 / 普通 100）
- **飞书多维表格同步**（可选功能，默认关闭）

### 2. 养生日常

养成健康生活习惯，打卡赚积分。

- **日常习惯打卡** — 预设喝水、八段锦、梳头发、早睡等习惯，每次打卡 30 积分
- **自定义习惯** — 点击 "+" 卡片添加自己的习惯，支持设置名称、描述、每日目标次数，18 种 emoji 图标可选
- **运动记录** — 预设跑步、游泳、跳舞、瑜伽等运动，记录运动时长
- **自定义运动** — 添加自己的运动项目，支持 18 种运动 emoji、6 种莫兰迪配色方案、注意事项（每行一条）
- 运动积分按时长计算（每 10 分钟 10 积分，单次上限 300 积分）
- 每种运动附带注意事项和教程提示
- 习惯和运动均支持删除（点击 × 按钮）

### 3. 学习

管理你的阅读和学习计划。

- **书架管理** — 记录书名、作者、阅读理由、计划完成时间
- **阅读打卡** — 更新阅读进度，打卡获得 100 积分
- **课程管理** — 追踪在线课程或线下课程进度
- **笔记记录** — 随手记录学习笔记和心得

### 4. 心愿板

用积分奖励自己，让努力有回报。

- 添加心愿目标（如旅行、购物、美食等）
- 设置每个心愿所需的积分数
- 积分充足时即可兑换
- 已兑换 / 待兑换状态管理
- 兑换后扣除对应积分

### 5. 成就清单

可视化你的成长足迹。

- 统计总积分、完成任务数、打卡天数
- 可视化展示所有完成的任务、习惯、运动、心愿
- 成就徽章系统，里程碑解锁

## 积分系统

| 行为 | 积分 |
|------|------|
| 完成紧急工作任务 | 200 |
| 完成重要工作任务 | 150 |
| 完成普通工作任务 | 100 |
| 习惯打卡 | 30 / 次 |
| 运动记录 | 10 / 10分钟（上限 300） |
| 学习打卡 | 100 |

积分可在心愿板兑换奖励，形成"努力 → 积分 → 奖励"的正向循环。

## 设计系统

### 配色方案（莫兰迪灰粉）

| 变量 | 色值 | 用途 |
|------|------|------|
| `--bg` | `#F0E6E8` | 主背景 |
| `--surface` | `#EDE0E3` | 卡片背景 |
| `--surface-2` | `#E5D5D8` | 次级卡片 |
| `--gold` | `#B08585` | 主色调 |
| `--gold-dim` | `#8A6A6E` | 深色强调 |
| `--text` | `#4A3A3E` | 主文本 |

### 设计细节

- **字体** — Manrope + 系统中文字体（PingFang SC / Hiragino Sans GB）
- **圆角** — 卡片 16px，按钮 12px，大卡片 22px
- **顶部安全区** — 深色莫兰迪色条（`#9A7272` → `#B08585` 渐变），高度为安全区的 1.5 倍
- **底部安全区** — 侧边栏和语音栏自动延伸，消除色差空白带
- **桌面端预览** — 手机框架模拟（390 × 844px），带状态栏和刘海
- **移动端** — 全屏 APP 模式，去掉手机壳

## 快速开始

### 在线体验

直接访问 GitHub Pages 部署的页面：

```
https://mandy610392709-cpu.github.io/game-life-app/
```

### 本地使用

1. 下载以下文件到同一目录：
   - `index.html` — 主应用
   - `manifest.json` — PWA 配置
   - `sw.js` — Service Worker
   - `app-icon.png` — 应用图标
   - `butterfly-clean.png` — Logo 图标
2. 用浏览器打开 `index.html` 即可使用
3. 如需 PWA 功能（离线缓存、安装到桌面），需通过 HTTPS 或本地服务器访问

### 安装到手机桌面

**iOS (Safari):**
1. 用 Safari 打开应用页面
2. 点击底部分享按钮
3. 选择"添加到主屏幕"
4. 点击"添加"，桌面会出现 APP 图标

**Android (Chrome):**
1. 用 Chrome 打开应用页面
2. 点击右上角菜单
3. 选择"添加到主屏幕"
4. 或等待浏览器自动弹出安装提示

安装后即可全屏使用，如同原生 APP，支持离线访问。

## 自定义设置

### 个人设置

点击左上角 Logo 进入个人设置：
- 修改昵称
- 选择应用图标（预设 emoji 或自定义上传）
- 飞书同步开关

### 自定义习惯和运动

在"养生日常"页面：
- 习惯打卡区域点击 "+" 卡片 → 添加自定义习惯
- 运动记录区域点击 "+" 卡片 → 添加自定义运动
- 自定义项目支持删除（点击 × 按钮）

### 飞书同步（可选）

飞书同步默认关闭。如需启用：
1. 在个人设置中打开"飞书同步"开关
2. 需自行对接飞书多维表格 API
3. 飞书表格需设置为"任何人可通过链接查看"

## 数据与隐私

- 所有数据存储在浏览器 localStorage 中，完全本地化
- 不收集任何用户数据，不发送任何分析统计
- 飞书同步为可选功能，默认关闭，仅在用户主动开启时生效
- 清除浏览器数据会丢失所有记录，建议定期截图备份
